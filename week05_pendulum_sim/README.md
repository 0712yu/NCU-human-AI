## 人机协同三反思
### 反思1：意图设计思考
做这个实验的时候，我向AI提出明确要求，只用一个HTML文件写单摆模拟，不能用外部的资源。我把需求写的很清楚，限定好条件，生成的网页下载下来就能直接打开运行，不用额外配置环境。

### 反思2：报错自愈思考
代码生成完成后，我测试发现重置按钮点了没反应。我把网页控制台里的报错信息发给AI，告诉它出现的问题，让AI修改代码。最后它修复了bug，页面就可以正常使用了。

### 反思3：人机协同思考
AI可以快速帮我写出需要的代码，节省大量写代码的时间。但是AI不知道我的全部要求，也不会主动测试页面有没有问题，指令不明确也无法运行。甚至我没有GitHub账号需要注册才能运行这个问题也不能主动提出 需要我来提出任务、测试运行、找出bug，人和AI分工配合，最后完成这次实验。
